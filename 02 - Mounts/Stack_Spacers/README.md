# Stack spacers

`ACwing_Stack_Spacers_S1x4_S2x4.stl` is one plate with 8 spacers, OD 4.5 / ID 2.3 mm, PETG, printed flat at 100 % infill:
- **S1, 2.57 mm** (×4): from the ESC 1S top to the lower damping ball of the FC mount;
- **S2, 3.57 mm** (×4): from the upper ball to the GPS rev A bottom, GPS option only.

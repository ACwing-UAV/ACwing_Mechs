# Stack spacers

`ACwing_Stack_Spacers_A1_S1x4_S2x4.stl` is one plate with 8 spacers, OD 4.5 / ID 2.3 mm, PETG, printed flat at 100 % infill.
Heights are for **1.0 mm boards** and the QUARKZMAN M2 damping balls (H 6.0, slot 1.14 mm, 2.43 mm above / below the
board), 2026-11-08:
- **S1, 2.57 mm** (×4): from the ESC 1S top (z −1.0) to the lower ball of the FC mount (z 1.57);
- **S2, 3.57 mm** (×4): from the upper ball (z 7.43) to the GPS rev A bottom (z 11.0), GPS option only.

With the 1.6 mm boards and the silicone grommets (2026-11-06 … 11-07) they were 2.8 / 3.8 mm.
